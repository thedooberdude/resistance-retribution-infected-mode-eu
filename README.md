# Resistance: Retribution – Infected Mode (EU)

A PSP plugin that enables the Infected Mode state in the European version (UCES-01184) of Resistance: Retribution without requiring a PlayStation 3.

## Confirmed on

- PSP-1000
- ARK-4
- Resistance: Retribution (European UCES-01184)

## Observed effects

- Yellow health bar
- Health regeneration
- Infected appearance
- Infected Intel menu
- Infected voice lines

## Installation

1. Copy `resistance_retribution_infected_eu.prx` to `ms0:/SEPLUGINS/`
2. Enable it as a GAME plugin in ARK-4.
3. Launch the game.

## Compatibility

This plugin contains a compatibility guard and is intended only for the verified European UCES-01184 release.
